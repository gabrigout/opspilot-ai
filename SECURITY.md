# Security Policy

OpsPilot AI is an independent demonstration project (simulated data only), but security reports are welcome.

## Reporting a vulnerability
Please use GitHub's **private vulnerability reporting** (Security tab → *Report a vulnerability*) instead of a public issue. Do not include real credentials or personal data in reports.

## Scope and known limitations
The implemented protections and the documented limitations (token storage, in-memory rate limiting/revocation, demo credentials for local use only) are described in [docs/SECURITY.md](docs/SECURITY.md).

## Supported versions
Only the latest commit on `main` is supported.
